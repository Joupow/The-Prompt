👋 Welcome to my side quest project.

At first, I just wanted to write a simple prompt to learn to code and to automate tasks.  

One thing led to another, and it turned into a narrative mini-RPG for learning **Python, PowerShell and Linux** by playing right in the AI chat, with nothing to install.

A post-collapse world, an AI stripped of its memory, and a save file you carry yourself from one model to the next. All driven by a single instructions file.

I hope you'll learn or brush up while having fun. 

Enjoy 🎮
