👋 Welcome to my little side quest.

It started as a simple prompt to help me learn coding and automation.

Then it grew into a learning RPG where you build **Python, PowerShell and Linux** skills by actually playing inside an AI chat. No setup, no install, no separate platform.

The setting is a world after the collapse. Your guide is an AI that cannot remember you, and your save file is the one thing that carries your progress from one model to the next.

Under the hood, it is deliberately simple: a handful of text files for the game engine, your save, and an optional story layer.

I hope it can help you learn from scratch, sharpen old skills or simply practice in a different way.

Enjoy 🎮
